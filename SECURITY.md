# Security policy

## Supported versions

Security fixes are applied to the latest release on `main`.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's **Report a vulnerability** private security advisory flow for this repository. Include the affected version, reproduction, impact, and any suggested mitigation.

Maintainers aim to acknowledge a complete report within 5 business days and will coordinate disclosure after a fix is available. Never include real tokens, private issue content, or personal recordings in a report; use redacted test data.

For deployment guidance and threat boundaries, read [docs/SECURITY.md](docs/SECURITY.md).
